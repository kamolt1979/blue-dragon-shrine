# ตำหนักมังกรฟ้า (Tamnak Mangkon Fa)

เว็บแอปพลิเคชันศาลเจ้าจีนดิจิทัล 7 วัน ในธีมมงคลสีแดงทอง (UX/UI Prototype) รองรับการเปิดใช้งานผ่านมือถือและเว็บเบราว์เซอร์

## อัปเดตล่าสุด (ความคืบหน้าภาพวาด Portrait)
- **ตราสัญลักษณ์ตำหนักมังกรฟ้า**: ใช้ภาพวาดมังกรจีนสีฟ้า (`.jpg`) พร้อมกรอบและออร่าสีฟ้ากระพริบ (แทนไอคอนเวกเตอร์) ในทุกตำแหน่งตั้งแต่หน้าเข้าตำหนักถึงการ์ดแชร์
- **วิหารชั้นที่ 1 (เปิดสมบูรณ์ · ภาพ Portrait วาดจริงครบ 7/7 วันตามลำดับชั้น神階)**:
  - อาทิตย์: เทพทวารบาล เมิ่งเสิน (門神)
  - จันทร์: ตี่จู้เอี้ย เจ้าที่ประจำเรือน (地主爺)
  - อังคาร: เสือเจ้าที่ หู่เหยีย (虎爺)
  - พุธ: แป๊ะกง / โทวตี้กง (土地公)
  - พฤหัสบดี: เทพเจ้าเตาไฟ (灶君)
  - ศุกร์ (วันเกิด): เจ้าแม่ทับทิม หม่าโจ้ว (媽祖)
  - เสาร์: เทพเจ้าหลักเมือง เฉิงหวงเยีย (城隍爺)
- **ทำเนียบชั้น 2–7 (หอบูชาความหรูหราเพิ่มระดับตามชั้น 2F → 7F)**:
  - ออกแบบหน้าบูชาเพิ่มความโอ่อ่าขึ้นเรื่อยๆ ทุกชั้น (หอไหมทองคำ → เสามังกรคู่ราชสำนัก → หยกเมฆามงคล → แท่นบัวทองรัศมี 3 ชั้น → บุษบก 2 ชั้น → ยอดเจดีย์ 24K Gold เก้าชั้นฟ้า)
  - มีภาพ Portrait วาดจริงแล้ว 8 องค์ (ชั้น 2 กวนเป๋ง, เฒ่าจันทรา, นาจา, ไฉ่ซิงเอี้ย · ชั้น 3 กวนอู, เหวินชาง · ชั้น 5 กวนอิม · ชั้น 6 เสวียนเทียนซ่างตี้) ส่วนองค์ที่กำลังรอภาพวาดแสดง **กราฟิก Dummy แยกเพศชาย-หญิง (`♂ เทพบุรุษ` / `♀ เทพสตรี`)** ในธีมแดงทองให้ชมชัดเจนทุกองค์

## ฟีเจอร์หลัก
- **จำกัดการสักการะ 1 ครั้ง/วัน** และ **ทำบุญบริจาคได้ไม่จำกัดครั้ง** (รองรับ PromptPay QR และบัตรเครดิต/เดบิต)
- **เสี่ยงทาย 4 ศาสตร์จีน**: เซียมซี, ปัวะปวย, วงล้อเสี่ยงทาย 8 ทิศ และกังหันเทพแชกง
- **โปรไฟล์ & การ์ดแชร์โซเชียล**: อัปโหลดรูปโปรไฟล์จากมือถือ/เลือกอวาตาร์ พร้อมการ์ดแชร์ผลเสี่ยงทายและอนุโมทนาบัตรสำหรับ IG Story / LINE / Facebook / TikTok
