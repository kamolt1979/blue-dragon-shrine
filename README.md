# ตำหนักมังกรฟ้า (Tamnak Mangkon Fa)

เว็บแอปพลิเคชันศาลเจ้าจีนดิจิทัล 7 วัน (UX/UI Prototype) รองรับการเปิดใช้งานผ่านมือถือ

## ฟีเจอร์หลัก
- **วิหารชั้นที่ 1 (ภาพวาด Portrait องค์เทพจีนครบทั้ง 7 วัน)**: อิงตามโหราศาสตร์และปาจื่อ พร้อม **เจ้าแม่ทับทิม** ประจำวันเกิด (วันศุกร์)
- **จำกัดการสักการะ 1 ครั้ง/วัน** และ **ทำบุญบริจาคได้ไม่จำกัดครั้ง** (รองรับ PromptPay QR และบัตรเครดิต/เดบิต)
- **เสี่ยงทาย 4 ศาสตร์จีน**: เซียมซี, ปัวะปวย, วงล้อเสี่ยงทาย 8 ทิศ และกังหันเทพแชกง
- **โปรไฟล์ & การ์ดแชร์โซเชียล**: อัปโหลดรูปโปรไฟล์จากมือถือ/เลือกอวาตาร์น่ารัก พร้อมสร้างการ์ดแชร์ผลเสี่ยงทายและอนุโมทนาบัตรสำหรับ IG Story / LINE / Facebook / TikTok
